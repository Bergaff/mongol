# Монгол хэл

Интерфейсный прототип сайта курса монгольского языка. Запуск: `npm install`, затем `npm run dev`. Проверка сборки: `npm run build`.

Это не готовый к запуску MVP: уроки и записи ожидают проверки преподавателем и носителем; авторизация, платежи, хранение записей, настоящая админка, SSR и инфраструктура Cloudflare не подключены. Страницы правовых документов являются черновиками. Раздел `/admin` хранит только заметки об источниках в localStorage текущего браузера, не защищён и не предназначен для конфиденциальных данных или загрузки текстов книг.

Общие решения и план проекта: [PROJECT_BIBLE.md](PROJECT_BIBLE.md). Черновик первого урока хранится в `content/lesson-01.json` и требует проверки преподавателем и носителем.
