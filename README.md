# Монгол хэл

Интерфейсный прототип сайта курса монгольского языка. Запуск: `npm install`, затем `npm run dev`. Проверка сборки: `npm run build`.

Это не готовый к запуску MVP: уроки и записи ожидают проверки преподавателем и носителем; авторизация, платежи, хранение записей, настоящая админка, SSR и инфраструктура Cloudflare не подключены. Страницы правовых документов являются черновиками. Раздел `/admin` защищён паролем через Cloudflare Pages Functions при развёртывании на Pages; локальный Vite сам по себе защиту не запускает. Локальный помощник позволяет извлечь текст PDF на собственном компьютере, см. `local-helper/README.md`. ИИ-анализ и загрузка книг на сайт не подключены.

Общие решения и план проекта: [PROJECT_BIBLE.md](PROJECT_BIBLE.md). Черновик первого урока хранится в `content/lesson-01.json` и требует проверки преподавателем и носителем.

## Защита админки на Cloudflare Pages

В настройках Pages → Settings → Variables and Secrets добавьте секрет `ADMIN_PASSWORD`: уникальный случайный пароль длиной не менее 16 символов. Задайте его для Production и при необходимости отдельно для Preview, затем повторно разверните сайт. Без секрета `/admin` возвращает 503. Менять пароль означает аннулировать все сессии. Cookie действует до 8 часов. Для выхода есть кнопка в админке. Не помещайте пароль в Git, frontend или чат.

Обязательно настройте Cloudflare WAF rate limiting для POST `/admin` и предпочтительно Cloudflare Access перед открытием админки: встроенного ограничения попыток, MFA и индивидуальных пользователей пока нет. Это только защита доступа к странице в Cloudflare, не полная система безопасности и не защита локального Vite. Рабочие заметки в админке хранятся в localStorage этого браузера; секреты и документы туда не добавлять.
