# Локальный помощник

Первый этап: извлечение текста из PDF целиком, с разбивкой по страницам. Можно вручную запустить пробный анализ одной-трёх соседних страниц в локальной Ollama. Помощник может последовательно разбирать выбранный диапазон страниц, но не делает общую сводку книги, не создаёт уроки, не обрабатывает MP3 и не отправляет содержимое в облако. Не импортируйте материалы без проверки прав. Локальная библиотека может содержать защищённые тексты, не публикуйте её и не добавляйте в Git.

## Запуск на Windows

1. Убедитесь, что установлен Python 3.10 или новее. Скачайте ZIP репозитория, выбрав ветку `arena/392fbcc6-mongol`, и **распакуйте архив целиком**.
2. Откройте распакованную папку и дважды нажмите `start-helper.bat`. При первом запуске он создаст локальное окружение и установит необходимые зависимости через интернет. Если Windows не находит Python, переустановите Python с опцией Add Python to PATH.
3. Скопируйте токен из открывшегося окна в раздел «Подключение к компьютеру» админки `https://mongol-b2s.pages.dev/admin`. Токен меняется при каждом запуске; не отправляйте его никому. Оставьте окно открытым во время работы.
4. После подключения в разделе «Импортированные книги» можно открыть сохранённую книгу и просмотреть извлечённый текст по страницам. Чтобы добавить ещё одну, выберите PDF и подтвердите право на обработку. Папка библиотеки: `.local-data\library` внутри папки проекта. Если хотите хранить её на другом диске, сначала распакуйте туда весь проект. Закройте окно помощника для остановки.

Батник рассчитан на основной адрес `https://mongol-b2s.pages.dev`. На preview-адресе с другим доменом подключение не сработает: для него нужен запуск помощника с соответствующим `--origin`. Не меняйте origin на адрес, которому не доверяете.

## Linux / macOS

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r local-helper/requirements.txt
.venv/bin/python local-helper/helper.py --origin https://mongol-b2s.pages.dev
```

## Ограничения и безопасность

Сервис слушает только `127.0.0.1:8765`, проверяет Origin, Host и случайный токен, который не хранится на сайте. Не меняйте адрес прослушивания на 0.0.0.0 и не публикуйте порт в интернет. Браузер может требовать разрешение на доступ к локальной сети или блокировать соединение. Не открывайте локальный помощник при недоверенных расширениях браузера или других пользователях компьютера. Данные в `.local-data/library` внутри папки проекта не шифруются, защищайте доступ к компьютеру. Папка исключена из Git. Батник размещает виртуальное окружение в `.venv`, временные файлы в `.local-data/tmp` и отключает кэш pip. Сам Python остаётся там, где уже установлен; Windows и браузер могут использовать собственные системные каталоги и кэши. Если старая версия уже сохранила библиотеку в `C:\Users\<имя>\mongol-library`, автоматически она не переносится и не удаляется: при необходимости перенесите её JSON-файлы вручную в `.local-data\library`. Ограничение 50 МБ на PDF; сканы и защищённые PDF не поддерживаются. Пустые страницы могут требовать OCR. Повторный импорт идентичного PDF определяется по SHA-256 и не создаёт новую копию. Старые дубликаты автоматически не удаляются: в админке можно вручную удалить выбранную запись после подтверждения. Удаляется только сохранённый текст; исходный PDF не затрагивается.

## Обновление без потери библиотеки

В новой версии скачайте и распакуйте архив в отдельную папку. Если книги уже были импортированы, скопируйте папку `.local-data` из старой папки проекта в новую, чтобы сохранить и библиотеку, и результаты анализа, не удаляя старую копию до проверки. Перезапустите `start-helper.bat` из новой папки и подключитесь с новым токеном. Список покажет только книги из папки проекта, в котором запущен помощник.

## Список моделей Ollama

Запустите установленную Ollama на том же компьютере, что и помощник. Подключите помощник в админке и нажмите «Показать модели Ollama». Помощник обращается только к `http://127.0.0.1:11434/api/tags`, через доверенный токен и проверенный origin. Адрес Ollama и папку моделей он не меняет; список показывает то, что видит запущенная Ollama, в том числе если она уже настроена на `E:\ollama_models`. Ничего не скачивается, содержимое книг в Ollama не передаётся. Если список пуст, проверьте, что модели видны в самой Ollama и что она запущена с нужной конфигурацией. Последовательный анализ диапазона доступен; общая сводка книги и генерация уроков пока не реализованы.

## Пробный анализ страниц

Запустите Ollama и помощник, затем подключите его к админке. В разделе «Изучить страницу» выберите книгу и диапазон от одной до трёх страниц PDF, подтвердите право на локальную обработку. Передаётся максимум 3500 символов для одной страницы или по 1600 символов с начала каждой при выборе нескольких страниц в `qwen2.5:7b` на локальном `127.0.0.1:11434`; пользовательские внешние адреса, загрузка модели и облачные API не используются. За один раз разрешена одна задача. Настройки: контекст 4096 токенов, ответ до 450 токенов, до 4 потоков CPU; нагрузка на GPU и вентиляторы возможна. Ollama получает `keep_alive: 0` для выгрузки после ответа, но иные пользователи модели могут удерживать её в памяти.

Результат и сведения о странице хранятся в `.local-data/analyses` в папке проекта, без шифрования. Он может содержать неточности и фрагменты источника; не публикуйте без проверки прав и специалиста. Кнопка остановки не прерывает уже отправленный запрос: он завершится, и результат будет отброшен. При закрытии помощника незавершённый анализ будет отмечен как прерванный после следующего запуска.

Модель получает отдельные номера страниц и инструкции отделять выводы, подтверждения, сомнения и идеи. Её ссылки, цитаты и выводы **не проверяются автоматически** и могут быть неверными. В результатах показывается, какие страницы и сколько символов отправлены, а также отмечаются обрезанные и пустые страницы. Текст страниц можно открыть в библиотеке; для проверки ошибок извлечения сверяйте с оригинальным PDF, который помощник не хранит. Для последовательного анализа большего диапазона используйте раздел «Разобрать страницы».

## Последовательный анализ диапазона

Подключите обновлённый помощник, выберите книгу и номера первой и последней страницы PDF в разделе «Разобрать страницы». Один запуск ограничен 500 страницами и 2000 частями. После подтверждения прав непустой извлечённый текст делится на части до 2400 символов и обрабатывается последовательно; страницы без текста перечисляются отдельно. Завершённые результаты сохраняются в `.local-data/analyses` после каждой части. Кнопка остановки ждёт завершения текущего запроса и сохраняет его результат. После перезапуска помощника незавершённую работу можно продолжить, если исходный извлечённый текст не изменился. При изменённом или удалённом источнике начните новый анализ. Для просмотра используйте «Читать результаты» и переключайте части.

В процессе отправляется один запрос к установленной локальной модели `qwen2.5:7b`; `num_ctx=4096`, `num_predict=450`, `num_thread=4`, `keep_alive=0`. Ограничение числа потоков не ограничивает загрузку GPU, вентиляторы могут шуметь; выгрузка и повторная загрузка модели между частями могут замедлить обработку. Браузер можно закрыть, пока окно помощника работает; закрытие помощника прервёт обработку, а Ollama может какое-то время завершать активный запрос. Фрагменты могут разрывать объяснение, и модель не видит всю книгу одновременно. Цитаты, выводы и монгольский язык требуют проверки. Общую сводку или уроки функция не создаёт.

### Экспорт и время обработки

Кнопка «Скопировать все результаты» собирает все готовые части выбранного анализа, указанный диапазон PDF, число частей, пустые страницы и время запросов к Ollama. Время новых частей измеряется на компьютере от отправки запроса до ответа, включая возможную загрузку модели; в старых результатах оно не записано и указывается как «не измерено». Сводка по странице суммирует только готовые части; обработка может быть частичной. Если браузер не разрешает автоматическое копирование, появится поле для ручного копирования. Результаты не отправляются автоматически: содержимое буфера может включать фрагменты материалов, поэтому проверяйте права и содержание перед отправкой в чат. Номера страниц и ответы нейросети не подтверждаются автоматически.
