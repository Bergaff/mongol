# Локальный помощник

Первый этап: извлечение текста из PDF целиком, с разбивкой по страницам. Не анализирует книги нейросетью, не создаёт уроки, не обрабатывает MP3 и не отправляет содержимое в облако. Не импортируйте материалы без проверки прав. Локальная библиотека может содержать защищённые тексты, не публикуйте её и не добавляйте в Git.

## Запуск на Windows

1. Убедитесь, что установлен Python 3.10 или новее. Скачайте ZIP репозитория, выбрав ветку `arena/392fbcc6-mongol`, и **распакуйте архив целиком**.
2. Откройте распакованную папку и дважды нажмите `start-helper.bat`. При первом запуске он создаст локальное окружение и установит необходимые зависимости через интернет. Если Windows не находит Python, переустановите Python с опцией Add Python to PATH.
3. Скопируйте токен из открывшегося окна в раздел «Подключение к компьютеру» админки `https://mongol-b2s.pages.dev/admin`. Токен меняется при каждом запуске; не отправляйте его никому. Оставьте окно открытым во время работы.
4. Выберите PDF и подтвердите право на обработку. Папка библиотеки: `C:\Users\<имя>\mongol-library`. Закройте окно помощника для остановки.

Батник рассчитан на основной адрес `https://mongol-b2s.pages.dev`. На preview-адресе с другим доменом подключение не сработает: для него нужен запуск помощника с соответствующим `--origin`. Не меняйте origin на адрес, которому не доверяете.

## Linux / macOS

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r local-helper/requirements.txt
.venv/bin/python local-helper/helper.py --origin https://mongol-b2s.pages.dev
```

## Ограничения и безопасность

Сервис слушает только `127.0.0.1:8765`, проверяет Origin, Host и случайный токен, который не хранится на сайте. Не меняйте адрес прослушивания на 0.0.0.0 и не публикуйте порт в интернет. Браузер может требовать разрешение на доступ к локальной сети или блокировать соединение. Не открывайте локальный помощник при недоверенных расширениях браузера или других пользователях компьютера. Данные в `~/mongol-library` не шифруются, защищайте доступ к компьютеру. Ограничение 50 МБ на PDF; сканы и защищённые PDF не поддерживаются. Пустые страницы могут требовать OCR. При повторном импорте создаётся новая копия извлечённого текста.
